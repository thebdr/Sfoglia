# C-013: Spreadsheets and delimited tables

## Design (2026-10-18)

- `src/sheet.rs` (pure): a delimited text parses through the `csv` crate (RFC 4180, `flexible` for ragged
  records, no header handling of its own) into a `Grid` of string fields with each record's byte span, so a cell
  edit re-writes that record alone; `detect_delimiter` counts comma, semicolon, tab and pipe outside quotes over
  the first twenty lines and keeps the candidate that splits them into the most fields the same way (a `.tsv`
  is tabs regardless); `format_record` writes a record back quoted only where needed. An Excel workbook reads
  through `calamine` (`open_workbook_auto`: xls, xlsx, xlsm, xlsb, the templates) into sheets of typed `Cell`s:
  `Data::Int`/`Float` as their own digits (`format_number`: fifteen significant digits, the shortest exact form
  preferred), `DateTime` through our own serial-to-civil conversion (no chrono: the 1900 system's phantom
  1900-02-29 kept at serial 60, the 1904 epoch honoured for xlsx), booleans `TRUE`/`FALSE`, errors as calamine
  prints them, a formula as the cached value `worksheet_range` gives; merged regions from
  `merge_cells_by_sheet_name` for the xlsx family (calamine exposes none for xls). Column widths and number
  formats are not exposed by calamine: columns are sized to their content and the workbook's own widths and
  formats are parked as P-029.
- `src/viewers/sheet_view.rs`: the kit's `TableState<SheetDelegate>` (virtual rows, resizable columns,
  sortable headers, cell selection, a row-number column) over the current sheet's cells with a display order the
  sort permutes; `perform_sort` follows the kit's own cycle on a header click (Default → Descending →
  Ascending → Default, so a first click sorts descending, as the kit draws it); `compare_cells` puts numbers
  before text, text case-insensitively, and the delegate keeps empty cells last in either direction. The
  search field (`sheet-search`) finds the next cell containing the text in display order from the selected
  cell on; the edit field (`sheet-edit`) holds the selected cell and Enter writes it back into the raw text
  through the text viewer (`replace_all` + `note_edit`, as the data view's pretty-print does), the grid
  re-parsed; Ctrl+Shift+D toggles the raw text as the data view does; the Reload / Keep mine bar shows on the
  grid side; a workbook has a sheet bar and is read-only.
- Fixtures: `tests/fixtures/table.csv` (quoted commas, an embedded line break, doubled quotes, an empty field, a
  ragged last record), `table.tsv` (the same by tabs), `utf16.csv` (UTF-16 LE with a mark), `book.xlsx`
  generated by `cargo run -p xtask -- fixtures` (the `rust_xlsxwriter` crate: dates with formats, a datetime,
  booleans, a formula with its cached result, a merged range, a column width, three sheets one of them empty)
  and `book.xls` saved from it by Excel as a 97-2003 workbook through the desktop-control tools.
