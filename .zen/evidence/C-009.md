# C-009 — Images — lab notebook

The clause states intent; this file holds the research/spike log, sweeps, and design notes that would otherwise bloat the clause (clause altitude, C-012).

## 2026-10-16: design
- Decoding (`src/images.rs`, no GPUI): the image crate with the same decoder features the kit's GPUI enables
  (bmp, dds, exr, ff, gif, hdr, ico, jpeg, png, pnm, qoi, tga, tiff, webp), so no second copy of the crate is
  built; TGA has no signature, so the file extension is the fallback hint. Animations come from the GIF, APNG and
  WebP frame iterators with their delays. EXIF through kamadak-exif, ten fields in a fixed order. svgz through
  flate2. Font family and glyph count through ttf-parser.
- The extension lists (decodable, vector, font, unsupported) are asserted equal to the family's generated extension
  table, so a new extension in the clause must be placed in one of them. The clause gained ff, hdr and qoi, which
  the decoder handles and the original list lacked.
- Painting (`src/viewers/image_view.rs`): frames become GPUI `RenderImage` frames (BGRA by a channel swap, as GPUI's
  own loader does, straight alpha), turned by `image::imageops` for the quarter rotations, drawn by `img()` inside a
  box sized width × zoom by height × zoom on a checkerboard painted by a `canvas` only over the visible part.
  A measuring `canvas` reports the picture area's size into the view, so the fit zoom follows it one frame later;
  fitting never enlarges. Pan is the box overflowing a scrollable area.
- SVG: GPUI's own renderer rasterizes at a smoothing factor (the first headless run saw 160 × 120 for a 40 × 30
  file), and `RenderImage`'s scale factor is private, so the view rasterizes through resvg itself at the exact
  size, un-premultiplies tiny-skia's pixels, and rasterizes again whenever the zoom in effect moves (never below
  the file's size): sharp at every zoom, which is what "renders as vectors" promises.
- Fonts: the bytes go to `text_system().add_fonts`, the specimen is set in the family ttf-parser read. The headless
  test uses a system font (Arial on Windows, DejaVu Sans on Linux) and skips the specimen if none exists.
- Routing: a family with a viewer comes before the "text content opens as text" rule, or an SVG (text by content)
  would open in the editor. The C-004 and C-005 tests that expected a PNG's info rows now expect the image view;
  the hex test's "no viewer yet" case uses a fake .docx.
- Save-as: Ctrl+Shift+S asks for a new name through the window's save dialog; the extension picks the encoder.
  Farbfeld takes 16-bit RGBA, HDR 32-bit float RGB, JPEG RGB: the encoders refused 8-bit RGBA until converted.
- Disk, 2026-10-16: the recorded runs died with exit 0xC0000006 (a paging I/O error) when the host drive fell to
  1.6 GB free. The cause is not the repository: the Linux VM's virtual disk has grown to 65 GB over the Linux
  passes (every guest build adds to it and the file never shrinks by itself), next to a 16 GB system pagefile.
  The repository's target directory is 17 GB. The critics' probe binaries (five, 2.5 GB with their debug
  databases) were deleted. The runs are recorded again once the guest is cleaned and its disk compacted.
